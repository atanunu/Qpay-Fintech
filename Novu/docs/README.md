# Notification evidence and visual documentation
[Service README](../README.md) · [Complete specification](../../devdocs/Novu/00-INDEX.md).

CONTENT-SUMMARY.json is regenerated from the canonical catalogue and includes its SHA-256, total, scopes, themes and current no-live-activation status. FEATURES.json is generated from the service README by the shared documentation checker. SCREENSHOTS.json records that no installed Novu/application runtime screen has been captured.

Run the offline build to generate all 175 HTML/plain-text previews, fixtures and schemas in the ignored dist/ directory. Any published content-preview image must be labelled synthetic content evidence, not live Novu/provider evidence. Real service screenshots must meet the shared source-commit, environment, fixture, state, timestamp and file-hash requirements.
