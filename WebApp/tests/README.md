# Web test scope
`npm test` runs Vitest unit/contract tests and the explicit synthetic adapter suite. `npm run test:e2e` exercises the review app at a normal HTTP origin with Playwright/Chromium and axe. `npm run test:e2e:api` requires a running isolated local Go API plus the owner-only synthetic fixture generated by scripts/api-fixture.py; it exercises actual cookie/CSRF, PostgreSQL and local workers.

The review adapter is not a backend test. API tests use a synthetic external-execution provider and no real bank or email. No scenario proves production acceptance. Record exact commit, totals, failures/skips and environment in docs/VALIDATION.md. Screenshots must come from actual rendering and must not disclose credentials, MFA secrets or documents.
