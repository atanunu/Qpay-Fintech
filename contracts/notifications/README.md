# Notification contract workspace
The canonical content envelope and per-workflow JSON schemas are generated by [Novu/src/content.mjs](../../Novu/src/content.mjs). Run `npm --prefix Novu run build` to export all schemas and synthetic fixtures. [Catalogue](../../Novu/catalogue/emails.psv) defines stable IDs, audiences, scope and guard requirements.

[Delivery/Go contract specification](../../devdocs/Novu/04-CONTRACTS-AND-DELIVERY.md) defines required outbox, recipient, callback and state boundaries. Actual Go routes, physical migrations and provider-specific schemas remain to implement and publish in the shared OpenAPI/events workspaces. Never forward complete customer, financial or KYC records as notification payloads.
