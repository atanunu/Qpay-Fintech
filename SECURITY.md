# Security policy — planning stage
No deployed application or private vulnerability-reporting address is established by this pack. The repository owner must configure a private reporting channel before external release. Do not publish vulnerabilities containing credentials, customer records or exploitable private deployment details in public issues.

Planned controls and acceptance obligations are in [security/compliance](devdocs/project/07-SECURITY-AND-COMPLIANCE.md). Use synthetic fixtures, server-side scoped secrets, separate customer/staff permissions and reviewed financial actions. Do not conduct live provider tests or change production controls merely to validate documentation.
