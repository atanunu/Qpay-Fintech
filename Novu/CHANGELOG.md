# Novu change history

## 0.1.0 — 2026-09-22
Self-hosted architecture accepted. Added 164 deterministic email scenarios (134 core, 20 growth, 10 separately regulated), six built-in themes, strict payload validation, HTML/plain-text export, synthetic fixtures and 207 offline tests. Added an importable code-first factory with required policy/provider bindings, deliberately not a running production bridge. Added deployment/import, Community limitations, sender, consent, callback, recovery and release specifications. Actual Novu hosting, sync and delivery remain unverified and disabled.

## 2026-09-23
Added eleven customer-parity events (175 total; 145 core), preserving workflow versions and six themes. Go producers use committed state and recipient revalidation. No live email delivery.
