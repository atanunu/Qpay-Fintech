# Acceptance and release evidence

Source publication, automated verification, manual UAT, partner qualification and production activation are distinct. Keep manual cases not-tested until performed. Run frontend types/unit/builds, normal browser review/accessibility and actual Go/PostgreSQL browser integration; run full backend race/migration/private-object suites, container smoke, client helpers, Novu content and documentation checks. Record exact revisions and failures.

Runtime screenshots require source commit, route/state, UTC time, synthetic fixture, viewport and SHA-256. Never publish credentials, recovery codes, personal documents or real customer data. Source on main is a development delivery, not a production launch.
